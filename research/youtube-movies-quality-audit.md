# YouTube Movies Quality Audit

Audit date: 2026-11-16

## Verification method and limits

All 41 exact YouTube watch URLs were passed to the browser-backed web open tool. Ten returned a page title but no usable player state; exact-title searches returned indexed full-movie/channel metadata for Love Ni Bhavai and Pather Panchali, while their watch-page fetches failed. The remaining watch-page attempts returned fetch/cache errors. No YouTube API key or API access was available. This method cannot establish current playable/public status, embed permission, account/age prompts, region restrictions, or video duration. Accordingly, none is labelled working; all 41 are Unable to verify. Fetch errors are not evidence that a video is deleted.
